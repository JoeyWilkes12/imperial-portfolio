# Imperial 2.0

A standalone static portfolio draft built from the incumbent Imperial content.
The home page uses a progressively enhanced project evidence ledger and a live
Lorenz-system trace tied to the reservoir-computing report.

## Run locally

```sh
npm run serve
```

Open `http://127.0.0.1:4173/`.

## Verify

```sh
npm run check:links
npm run test:ui
```

The site has no runtime dependencies or build step. JavaScript-disabled and
reduced-motion experiences retain the complete content and a static trace.
